One interface for Gemini, OpenAI, Groq, a local model. The workshop doesn't care which vendor you picked this morning.

The underrated part

The system prompt
is the product

In a real harness it isn't a sentence, it's thousands of tokens. The workflow, the refusals, when to use which tool — that's prompt, not code.

Priority
Models treat it as highest-priority. A tendency, not a guarantee — session 6 shows where it gives out.
Tool descriptions count
Read by the model on every call. Prompt engineering wearing a JSON hat.
It costs, repeatedly
Re-sent on every turn of the loop. A 20-turn run pays for it 20 times.

The execution boundary

Model requests.
Application decides.

Model
Requests a tool call. Never runs it.
Application
Validates, classifies, maybe asks a human.
Tool
Runs. Returns a result.
Model
Receives the result, decides what's next.

Every security property in session 6 rests on this one fact.
