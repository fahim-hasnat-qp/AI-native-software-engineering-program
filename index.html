AI-native engineering

The QuestionPro AI-native software engineering program: from understanding models to building the systems around them.

Begin with Session 01

Course syllabus

12 sessions + 1 supplement

  1. Session 01

    Engineering in the AI era

    Follow a prompt through tokens, model training, attention, context and the agent harness that turns a model into a tool.

    Tokens Context windows Agent harnesses

  2. Session 02

    Repeatable AI workflows

    Encode engineering workflows with commands, skills and hooks: debugging, planning, tests, documentation and code review.

    Commands, skills & hooks Debugging Workflow enforcement

  3. Session 03

    Learning with AI

    Use AI as a tutor without skipping the struggle. Practice DSA, system design, databases and continuous learning.

    DSA practice System design Continuous learning

  4. Session 04

    AI applications & architecture

    Distinguish predictive, generative, agentic and embedded AI, then trace the application stack and its retrieval layer.

    Application types Architecture Vector databases

  5. Supplement

    Backend LLM integration

    Compare direct API integration and RAG for backend systems, explore model capabilities, and follow tokenization, training, vectors and token limits.

    Direct API integration RAG with backend Token limits

  6. Session 05

    LLM APIs & Cursor architecture

    Work with token costs, sampling parameters and tool calling, then look inside Cursor’s context, indexing and agent loop.

    API parameters Tool calling Inside Cursor

  7. Session 06

    Embeddings, demystified

    Build intuition for meaning as vectors, cosine similarity and how embeddings are learned from context.

    Embedding intuition Cosine similarity Learning embeddings

  8. Session 07

    Vector databases, hands-on

    Explore approximate nearest neighbors and HNSW, compare database options and query documents with Chroma.

    Indexes & ANN Database landscape Chroma demo

  9. Session 08

    RAG, hands-on

    Connect retrieval to generation in a document chatbot, then improve the pipeline with query rewriting and reranking.

    Retrieval pipeline Chatbot demo Improving retrieval

  10. Session 09

    Advanced RAG

    Address three retrieval failures with hybrid search, hypothetical document embeddings and corrective RAG.

    Hybrid search HyDE Corrective RAG

  11. Session 10

    Agent engineering foundations

    Build a runtime around a provider, system prompt and tool calls, with an explicit boundary between requests and execution.

    Provider System prompt Execution boundary

  12. Session 11

    The loop, the bill & retries

    Trace the agent loop, bound its work, distinguish history from state and understand caching, compaction and retry behavior.

    Agent loop Caching Retries

  13. Session 12

    The whole harness

    Bring the harness together: security, prompt injection, policy hooks, MCP, ACP, A2A and the complete workshop homework.

    Security MCP, ACP & A2A Complete homework
